\# BotSentinel API Documentation



\## Health Endpoint

GET /health



Checks whether the application is running.



\## Prediction Endpoint

POST /predict



Accepts network traffic features and returns

a prediction.



\## Dashboard

GET /



Displays the BotSentinel web dashboard.



\## Prediction Output



The API returns:

\- Prediction

\- Classification label

\- Confidence score

\- Security recommendations
