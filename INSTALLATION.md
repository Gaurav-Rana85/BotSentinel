\# BotSentinel Installation



\## Requirements

\- Python 3.11

\- Git

\- pip



\## Setup



Clone the repository:



git clone https://github.com/Gaurav-Rana85/BotSentinel.git



Enter the directory:



cd BotSentinel



Create virtual environment:



python -m venv venv



Activate on Windows:



venv\\Scripts\\activate



Install dependencies:



pip install -r requirements-serve.txt



Run application:



uvicorn app:app --reload
